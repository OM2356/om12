# 🐍 Python Mini Projects Collection

This repository contains two beginner-friendly Python console projects:

1. ✅ To-Do List Manager  
2. 🍔 Restaurant Menu Ordering System  

These projects are built using core Python concepts such as dictionaries, functions, loops, and conditional statements. Perfect for beginners who want hands-on Python practice.

---

# 📂 Projects Included

## 1️⃣ To-Do List Manager

A command-line To-Do List application that allows users to:

- Add tasks
- View tasks
- Mark tasks as completed
- Remove tasks
- Manage task status using a dictionary

### Features
- Add new tasks
- Prevent duplicate tasks
- Mark tasks as "Done"
- Delete tasks
- Display all tasks with status

### Menu Example

```text
1. Add Task
2. View Tasks
3. Mark Task as Done
4. Remove Task
5. Exit
```

---

## 2️⃣ Restaurant Menu Ordering System

A simple restaurant billing system where users can:

- View menu items
- Place food orders
- Select quantity
- Generate total bill
- Print receipt

### Features
- Dynamic food menu
- Multiple item ordering
- Quantity selection
- Automatic bill calculation
- Receipt generation

### Menu Example

```text
Burger : ₹50
Pizza  : ₹180
Pasta  : ₹60
Salad  : ₹40
Fries  : ₹45
Soda   : ₹30
```
